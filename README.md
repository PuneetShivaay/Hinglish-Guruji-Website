## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/PuneetShivaay/Hinglish-Guruji-Website.git
cd Hinglish-Guruji-Website
```

### 2. Run Locally
Open `index.html` directly in your browser:

- Double-click `index.html`, **or**
- Run a simple local server (e.g., using VS Code **Live Server** extension), or:

```bash
# Python 3
python -m http.server 8000
```

Visit `http://localhost:8000` in your web browser.
